WebDAV QS Support

WebDAV QS shares folders from your Mac with a web browser or a compatible WebDAV file app or media player. It runs from the Mac's menu bar; the apps on your other devices open the shared files.

Need help?

For a question, bug report or feature request, email Tony Scott at decking.ranker_8z@icloud.com.

Please include your macOS version, your WebDAV QS version, the device and app you are connecting from, and what happens when you try. A screenshot of the error or a relevant Activity entry can help. Do not send passwords or private files.

For setup and a full explanation of the settings, read the WebDAV QS Guide.

Common questions

I can't start sharing.

Give at least one user a password and a folder. The line under Not Sharing and any orange note on a user card explain what still needs attention.

My device can't connect.

Make sure the Mac is awake and Sharing is shown in the app. Copy the full address, including http:// or https:// and the port number. With Local network only on, the connection must arrive from a private network address; a mesh network or VPN can work, but guest Wi-Fi or client isolation may block it. Check that macOS Firewall allows WebDAV QS to accept connections. If Ask before new devices connect is on, allow the request in the Mac app or its notification.

A media player or VR app can't connect, but a browser can.

Check that the app supports WebDAV. Many players cannot accept WebDAV QS's self-signed HTTPS certificate. Set that user's Connection to HTTP or HTTP and HTTPS, then use the http:// address shown in WebDAV QS.

My password is rejected.

Click the user's name to check their sign-in details; passwords are case-sensitive. After repeated wrong attempts, the device is blocked briefly. Local network only is on by default, so a user connecting from a non-local address is refused even with the right password.

A folder or file is missing.

Confirm the folder is on that user's card and the file matches its selected file types. If the folder is on an external drive, reconnect the drive. A folder that has moved or been renamed may need to be added again.

I can't upload a file.

Turn on Uploads for that user. Uploads add new files; they cannot replace or delete files already in the shared folder.

I denied a device by mistake.

While sharing, open Settings › Security › Denied Devices and choose Allow or Ask Again.

Changes to users aren't saved.

WebDAV QS could not save to the macOS Keychain. Click Try Again and allow any Keychain permission prompt. Check that the warning has gone before quitting.

For App Store purchase, download or refund problems, use Apple's Report a Problem service. You can still email me if you are unsure where the problem lies.
